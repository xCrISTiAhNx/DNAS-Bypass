# DNAS-Bypass (Codes/Patches)

This repository contains the DNAS Bypass for games that require it to proceed. These codes are simple, functional, and non-invasive; they operate at precisely the right moment without causing game freezes or unwanted modifications.

The codes will be available in two formats:
1. **OPL/Codebreaker `(.cht)`** — It uses the game's `Game ID` as its name.
2. **PCSX2 `(.pnach)`** — It uses the game's `CRC` as its name (CRC computed automatically).

Generally, I create these codes myself using the necessary real-time tools, and they work on both emulators and consoles, although some are derived from krHACKen's excellent and efficient krHACKen's DNAS patcher CLI tool, available at: https://www.psx-place.com/threads/dnas-net-patcher.22813

These codes, along with further information about the games, will also be available in the "List of PlayStation 2 Online Games": https://docs.google.com/spreadsheets/d/15pfhL36qmC-iKr8MNjNXNLwgacG4VOmkfvwVxV5vGzo/edit?pli=1&gid=0#gid=0
